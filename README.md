# しずくあわせ
[![Play on GitHub Pages](https://img.shields.io/badge/Play-GitHub%20Pages-brightgreen?style=for-the-badge&logo=github)](https://t2k2pp.github.io/connect_oil_droplets/)

👉 **[今すぐブラウザで遊ぶ (GitHub Pages)](https://t2k2pp.github.io/connect_oil_droplets/)**  
*(スマートフォン・タブレット・PCの各ブラウザでクリックするだけでそのまま遊べます)*



水面に浮かぶしずくを、のばして、つなげて、とかして消す、ゆったり遊ぶパズルゲームです。

`index.html` をブラウザで開くだけで遊べます。外部ライブラリやネットワーク接続は不要で、WebGL2に対応したブラウザで動きます。

## モード

- **カラフル**: 色とりどりのしずくを色ごとにつなげます。同じ色がすべてつながると、その色がはじけて消えます。全色消すとクリアです。
- **ラーメン**: スープに浮かぶ油をひとつにまとめます。ぜんぶつながると丼の中央でまん丸になり、クリアです。醤油、塩、味噌、豚骨とスープが変わります。

進行とベストスコアはモードごとに別々に保存されます。

## 界面張力

タイトル画面と一時停止画面で変更できます。

- **よわい / ふつう / つよい / スライダー**: すべての色に同じ値を使います。弱いほど切れやすく、強いほど丸くまとまって切れにくくなります。
- **色ごと / スープごと**: 色やスープによって張力が変わります。

## 遊び方

- しずくをタッチして引っ張ると、のびます。離すと少し戻ります。
- 引っ張りすぎると切れます。切れた片は引き戻されませんが、触れるとつながります。
- 別のしずくには、指で引っ張って触れさせるとつながります。放っておいても勝手にはくっつきません。
- しずくは色が完成するまで消えません。小さなかけらは近くの同じ色へ戻っていきます。
- 5レベルごとにボーナスの水面があります。大きな色をなぞって細かく切り分けます。
- しずくがときどき落ちてきて水位が上がります。色を消すと下がります。
- 水位が100%を超えたまま20秒たつとゲームオーバーです。そのときは同じレベル、またはクリアしたレベルからやり直せます。

## キー操作

| キー | 動作 |
| --- | --- |
| Space | ひと息(しずくが止まり、同じ色が引き合う) |
| P / Esc | 一時停止 |

## 保存

スコア、ベスト、到達レベル、盤面、音量、界面張力はブラウザの `localStorage` に自動で保存され、再読み込みしても消えません。
