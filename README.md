# しずくあわせ

水面に浮かぶ色のしずくを、のばして、つなげて、とかして消す、ゆったり遊ぶパズルゲームです。

`index.html` をブラウザで開くだけで遊べます。外部ライブラリやネットワーク接続は不要で、WebGL2に対応したブラウザで動きます。

## 遊び方

- しずくをタッチして引っ張ると、のびます。離すと少し戻ります。
- 同じ色をすべてつなげると、その色がはじけて消えます。全部の色を消すとレベルクリアです。
- 5レベルごとにボーナスの水面があります。大きな色をなぞって細かく切り分けます。
- しずくがときどき落ちてきて水位が上がります。つなげると少し下がり、色を消すと大きく下がります。
- 水位が100%を超えたまま9秒たつとゲームオーバーです。そのときは同じレベル、またはクリアしたレベルからやり直せます。

## キー操作

| キー | 動作 |
| --- | --- |
| Space | ひと息(しずくが止まり、同じ色が引き合う) |
| P / Esc | 一時停止 |

## 保存

スコア、ベスト、到達レベル、盤面、音量はブラウザの `localStorage` に自動で保存され、再読み込みしても消えません。
